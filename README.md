# 股票视频整理台

这是一个本地运行的股票视频整理与股票池看板，用来把每天收到的视频观点沉淀成可维护的数据。

## 启动

```powershell
node server.js
```

打开：

```text
http://localhost:5173
```

## 主要功能

- 视频摘要：记录视频日期、来源、市场观点、关键内容和明日动作。
- 股票池：维护代码、名称、板块、入池逻辑、买入区间、止损、目标、仓位和风险。
- 实时行情：点击“刷新行情”后，通过东方财富公开行情接口更新现价、涨跌幅、成交额、换手率等字段。
- 本地数据：数据保存在 `data/stocks.json` 和 `data/summaries.json`。

## 每天整理流程

1. 把视频文件名或来源填入“新增/更新视频摘要”。
2. 把字幕、口播重点或截图文字粘贴到“关键内容”。
3. 提炼大盘方向、主线板块、个股代码、买入区间、止损位、目标位、仓位、风险。
4. 把提到的个股逐条加入股票池。
5. 点击“刷新行情”，盘中或盘后更新实时数据。
